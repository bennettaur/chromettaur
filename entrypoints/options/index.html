    Tab uniqueness

    Rules

    A new tab whose URL matches a rule below is collapsed into the existing matching tab. Two tabs are considered duplicates when they produce the same dedup key, computed from the URL via the rule's key strategy:

    exact
    Use the full URL (minus fragment) as the key. Two tabs collapse only if their URL and query string match exactly.
    ignoreFragment
    Strip the #… fragment, keep everything else. Equivalent to exact in this extension — both always strip the fragment.
    ignoreQuery
    Use only the origin + pathname. Different query strings to the same path collapse together (example.com/x?a=1 and example.com/x?a=2 → one tab).
    regexCapture
    Run a regex against the URL (without fragment); use capture group 1 as the key. Pick this when the "identity" of a page lives in a slice of the URL — e.g. the PR number, the JIRA ticket key. Examples:
    • GitHub PR (default): ^https://github\.com/([^/]+/[^/]+/pull/\d+)
    • JIRA ticket: ^https://[^/]+\.atlassian\.net/browse/([A-Z][A-Z0-9]+-\d+)

    Auto-group

    When a tab navigates to a URL matching a rule below, it is placed into the named group (created if absent). Patterns use Chrome's match-pattern syntax: https://github.com/*, https://*.atlassian.net/*. * in the host matches any subdomain (including the bare apex); * in the path matches any characters except a newline.

    GitHub PR status grouping

    Periodically asks the GitHub API for the status of each open PR tab (URL matches https://github.com/*/*/pull/*) and places the tab into a colored status group: PR: Draft (grey), PR: Ready (green), PR: Blocked (red), PR: Merged (purple), PR: Closed (pink). A PR is "blocked" when GitHub reports mergeable_state of blocked / dirty / behind / unstable (CI failing, merge conflict, branch behind, required-reviewer holds).

    Without a token, the GitHub API allows 60 unauthenticated requests per hour from your IP — enough for a handful of PRs at a 5-minute poll. For more, create a fine-grained PAT with read-only Pull requests scope on the repos you review and paste it below. The repo switcher uses the same token. The token is stored locally (chrome.storage.local) and is never synced.

    Keyboard shortcuts

    Alt+Shift+G opens the GitHub repo switcher: type part of a repo name, press Enter, and the repo opens in a new tab. Alt+Shift+H lists your tabs in the order you last viewed them. Change either shortcut at chrome://extensions/shortcuts.

    The repo switcher lists repos from the owners below. Repo lists come from the GitHub API (refreshed daily) plus any of these owners' repos you visit. Private repos only appear if the GitHub PAT above can read them. A fine-grained PAT covers a single owner, so use a classic PAT with repo scope (SSO-authorized where required) to cover several. Refresh uses the saved owner list, so save first.
